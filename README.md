Multi Model Document Intelligence

"An AI-powered document intelligence system that can read mixed documents and answer questions from the user".

The Problem & Solution
The Problem: Creating a System that can read mixed documents (PDFs with text, tables, charts, graphs, images, scanned pages) and answer questions about them. The system
needs to find answers by looking at multiple types of content and tell you exactly where in the document it found that answer.

The Solution: The created system can read mixed documents and can answer questions about them.
It can find answers by looking at multiple types of content and gives answer with source.

Tech Stack
* Framework: TanStack Start (React)
* Styling: Tailwind CSS
* Development Methodology: Prompted and generated using Lovable.
* AI & Tools: Built using Lovable.
